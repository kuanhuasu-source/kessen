# 決戰（Kessen）— MVP

網頁即時戰略遊戲。技術：TypeScript + Vite + Three.js。戰鬥核心（`src/sim`）沿用士氣模擬器，規則為設計文件 v2 士氣調整＋ v3 忍者調整（`src/sim/game-rules.ts`）。

## 開發
```bash
npm install
npm run dev          # http://localhost:5173 ；同一個 Wi-Fi 的手機可用終端機顯示的區網網址開啟
npm run typecheck
npm run build        # 一般建置，輸出到 dist/，可部署到 GitHub Pages
npm run build:single # 單一 HTML（dist/kessen-m1.html）
```

## 工具
- `node tools/pace.ts <局數> [設定名…]`：AI 對 AI 批次量測節奏（時長、潰走、重整、AI 撤退、主將與騎兵接戰、移動速度、箭矢命中）；設定含 `base`（legacy AI）、`steady`、`line`、`crane`、`craneT`
- `node tools/ai-diag.ts <局數> [steady|line|crane]`：AI 行為診斷（目標切換、目的地大跳、回頭、落單、待機、戰線散開）
- `node tools/matrix.ts <每組局數>`：忍者眾 3×3 對戰矩陣、各家總勝率、逆轉率、每步模擬耗時
- `node tools/ablate.ts <局數> <武田忍者眾> <上杉忍者眾> [變體…]`：逐項關掉機制看勝率變化（noKiri、noSahou、noRumor、noFog、noNinja…）
- `node tools/gen-art.mjs [--only id,id] [--group 名稱] [--force]`：Gemini 生成美術。自己電腦：`.env` 寫 `GEMINI_API_KEY=...`；雲端工作區（代理注入金鑰）：`NODE_USE_ENV_PROXY=1 GEMINI_API_KEY=proxy node tools/gen-art.mjs`
- `node tools/pack-art.mjs`：把 `art/out` 縮成遊戲用 WebP（`art/web`），幾秒完成；之後 `npm run build:single`
- `node tools/shot.mjs <網址或檔案#參數> <png> [寬] [高] [縮放] [腳本.mjs]`：無頭瀏覽器截圖（用工作區預裝的 Chromium）

## 結構
- `src/sim/`：戰鬥模擬（與士氣模擬器同一份程式；`sim.ts` 新增了陣線寬度、抵達朝向與畫面事件 `S.fx`；`ai.ts` 新增 `S.meta.aiSides` 與手動忍者）
- `src/game/orders.ts`：攻擊指令、弓兵自由射擊（依戰場迷霧）、舊的敵軍守備（測試用）
- `src/game/ninja.ts`：忍者顯示、物見範圍
- `src/game/skills.ts`：武將技、被動、軍略、忍術、忍者眾的名稱與說明
- `src/game/effects.ts`：陣亡、箭矢、揚塵、潰逃波及圈、朝向扇區
- `src/game/terrain.ts`：地形、據點、探明後的地形秘密
- `src/game/units.ts`：士兵 InstancedMesh、陣型槽位、接戰動作、陣亡、旗號
- `src/game/camera.ts`：RTS 鏡頭
- `src/game/hud.ts`：介面
- `src/game/art.ts`：2D 美術查表（肖像、圖示、家紋、插畫）
- `src/game/main.ts`：主迴圈（模擬固定 0.1 秒一步，畫面插值）與輸入
